## Data

- Intents: **53**, unique examples: **10495** (train 7638 / validation 1271 / test 1586)
- Leakage control: examples are grouped into **9008 paraphrase groups** (same content stems or character-trigram Jaccard ≥ 0.72; 2548 examples share a group). Whole groups are assigned to one split, stratified per intent, so a test sentence never has a near-copy in training.
- Augmentation is applied to **training items only**: 6 noisy copies each (typos and keyboard slips, dropped, swapped or joined words, neutral fillers) → 53442 training samples. 24 augmented copies that happened to equal a validation/test sentence were discarded.
- Class-balanced loss: sample weight √(mean count / intent count), between 0.49 and 1.49.
- Features: words, 5-character stems, stem bigrams, in-word character trigrams, first and last stem, a multilingual concept lexicon (concept tags and tag pairs, e.g. create + group), script and shape (digits, operators, codes, Cyrillic/Arabic/CJK, length); hashed into 2^19 buckets. Features seen in fewer than 3 training samples (mostly one-off typos) get no weight: 36,526 features are learned.

## Model

Multinomial logistic regression (softmax) trained with AdaGrad, L2 and feature dropout. The configuration and the epoch are chosen on validation macro-F1 (early stopping, patience 8):

| Learning rate | L2 | Feature dropout | Best epoch | Validation macro-F1 | Validation accuracy |
| --- | --- | --- | --- | --- | --- |
| 0.5 | 0.0001 | 0.5 | 6 | 90.1% | 89.6% |
| 0.5 | 0.0001 | 0.4 | 6 | 90.2% | 89.8% |
| 0.3 | 0.0001 | 0.5 | 19 | 90.4% | 89.9% |
| 0.5 | 0.0003 | 0.5 | 5 | 90.8% | 90.2% |
| 0.8 | 0.0001 | 0.5 | 4 | 90.3% | 89.7% |
| 0.5 | 0.0001 | 0.3 | 6 | 90.7% | 90.3% |

Chosen: learning rate 0.5, L2 0.0003, dropout 0.5, 5 epochs, averaged weights. A hidden layer was not added: with hashed sparse features it multiplies the size by the layer width, while richer features (concept lexicon, larger hash space) and more data gave the measured gains; the linear model also scores a message in well under a millisecond.

The shipped model is retrained with that configuration on every example (train + validation + test) for 5 epochs as the weight average of 3 runs with different seeds (a softmax regression's average is again one linear model), rows are centred, cut to the 24 strongest classes per feature and quantized to int8 with a per-row scale (|q| < 2 dropped), and stored as a label bitmask per row plus one byte per weight: 1,078,079 weights in 44,932 rows, written as raw bytes: **1449.1 KB** (budget 1536 KB). The test scores below come from the chosen configuration retrained on train + validation (8909 sentences), which never saw the test set; the holdout scores come from the shipped model.

## Limits

This is a small supervised classifier that routes messages to Hanogt AI's offline skills (site knowledge, agent actions, security tools, snippets, error explanations, calculator). It does not generate free text; open-ended answers come from the large language model configured on the server (see docs/HANOGT_AI.md). The test sentences were written by the same authors as the training data, so real-world accuracy on unusual phrasing will be lower; low-confidence predictions fall back to knowledge search.
