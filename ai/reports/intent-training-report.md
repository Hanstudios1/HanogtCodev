# Hanogt AI — intent model training report

Generated by `npm run ai:train` on 2026-09-30. Seed 20260930; feature version 2.

## Data

- Intents: **41**, unique examples: **1528** (train 1115 / validation 184 / test 229, stratified per intent)
- Training augmentation: 4 noisy copies per example (typos, dropped words, fillers) → 5575 training samples
- Features: words, 5-character prefix stems, stem bigrams and in-word character trigrams, hashed into 2^15 buckets

## Model

Multinomial logistic regression (softmax), AdaGrad (lr 0.15), L2 0.001, early stopping on validation accuracy (patience 12). Best epoch: **4**. The exported model is retrained on all examples for 4 epochs, pruned (|w| < 1/127 of the largest weight, at most 8 classes per feature) and quantized to int8: 93,542 weights, 396.8 KB.

## Limits

This is a small supervised classifier that routes messages to Hanogt AI's offline skills (site knowledge, security tools, snippets, error explanations, calculator). It does not generate free text; open-ended answers come from the large language model configured on the server (see docs/HANOGT_AI.md).
